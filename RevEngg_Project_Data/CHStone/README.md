# CHStone
This folder contains the two folder name C_code and verilog_code, it also contains one shell script name integrate_verilog.sh


## Folder Structure

* C_code:  
 The CHStone benchmark suite has been developed for C-Language based standard high-level synthesisable programs, this folder contains those programs.  
* verilog_code:  
 This folder contains (.v) files which is generated by xilinx vitis hls by taking c language programs as an input which is present in C_code folder.    
* intgrated_verilog.sh:  
 This shell script automates the three shell scripts(dat2verilog.sh, concat_verilog.sh, clean_verilog) in the verilog_code folder.  
  It will takes the root directory as the input which contains the folders having the mulitple .v files and you have to provide the output folder also in which the processed file will save.
  The details of the individually what these three scripts(dat2verilog.sh, concat_verilog.sh, clean_verilog) process is given in the [README.md](https://github.com/subhrendu1987/Reverse-Engineering/blob/master/CHStone/verilog_code/README.md) of the verilog_code.
  
  **To Run this integrated_verilog.sh**  
  
  ```
  bash integrated_verilog.sh verilog_code/ /path/output_folder  
  ```  
  The ouput_folder must be empty or only contains the .v files so the process file may save in that, we are putting this restriction cause we want to make the dataset of the verilog programs for our further use.
