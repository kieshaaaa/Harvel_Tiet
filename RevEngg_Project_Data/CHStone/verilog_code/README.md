# verilog_code 

This folder contains the folders which contains the multiple (.v) files which contains the modules of the single verilog program.  

Now to process on that multiple file we come with the four shell scripts in this folder:  
* dat2verilog.sh  
* concat_verilog.sh  
* clean_verilog.sh  
* add_module.sh  
  
**1.** dat2verilog.sh :  
   This shell script will work on the thing we can called merging the .dat file data into the .v file. Mostly .dat file contains the data of the array for optamization a xilinx vitis hls create a seperate .v file for calling the .dat file which contains the data of the array in form of the HexaDecimal or Binary.For Example: if a.v verilog file is calling the a.dat file, We are directly intializing the data of the array in the .v file where it is called.  
       
**Running the dat2verilog.sh**  
  
       
       bash dat2verilog.sh aes/ ./temp    
      
  
**2.** concat_verilog.sh :   
   This shell script simply concat the multiple .v files in the single .v file, Actually the multiple .v files contains the seperated modules which are calling one by one for the whole program, so in verilog we can write these modules in a single file.  
  
**Running the concat_verilog.sh**  
 
         
       bash concat_verilog.sh temp/ ./temp_concated
       
  
**3.** clean_verilog.sh :  
   This shell script remove the comments, extra information and timescale directive from the single .v file which is generated by the concat_verilog.sh    

 **Running the clean_verilog.sh**  
  
       
       bash clean_verilog.sh temp_concated/ ./temp_cleaned
         
  
**4.** add_module.sh :  
   This shell script simple add the endmodule in the end of each module present in the single .v file. while we concat the .v files into the single .v file some of the files dont have the endmodule at the end of the module so se are adding endmodule. 
  
**Running the add_module.sh**  
  
	  
        bash add_module.sh temp_cleaned/ ./final_temp
