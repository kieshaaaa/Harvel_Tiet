### Version 1
In this version, the code directly converts degrees to radians using a single statement for the conversion and prints the result. The usage of `float` instead of `double` is adhered to as per the instructions.

```c
#include <stdio.h>

#define PI 3.14f

int main() {
    float degrees, radians;
    printf("Enter angle in degrees: ");
    scanf("%f", &degrees);
    radians = degrees * (PI / 180.0f);
    printf("Angle in radians: ");
    printf("%f\n", radians);
    return 0;
}
```

int main() {
