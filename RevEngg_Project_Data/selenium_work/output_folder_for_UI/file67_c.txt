Here are three different versions of the provided C program code that calculate and display the perimeter of a hexagon, adhering to your constraints:

### Version 1: Using Direct User Input and Output
```c
#include <stdio.h>

int main() {
    float side;
    float perimeter;

    printf("Enter the length of the side: ");
    scanf("%f", &side);

    perimeter = side * 6;
    
    printf("Perimeter of the hexagon: ");
    printf("%.2f\n", perimeter);

    return 0;
}
```
