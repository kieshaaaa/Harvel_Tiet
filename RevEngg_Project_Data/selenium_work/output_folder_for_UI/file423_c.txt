### Version 1: Use of Ternary Operator

This version utilizes the ternary operator to simplify the decision-making process when determining the difference between the two numbers.

```c
#include <stdio.h>

int main() {
    int a, b, diff;

    printf("Enter first number: ");
    scanf("%d", &a);
    printf("Enter second number: ");
    scanf("%d", &b);

    diff = a > b ? a - b : b - a;

    printf("\nDifference between %d and %d is = %d", a, b, diff);
    return 0;
}
```
