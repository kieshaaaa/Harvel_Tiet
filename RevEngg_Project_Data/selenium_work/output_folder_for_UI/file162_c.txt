### Version 1: Using bitwise AND operator
In this version, we use the bitwise AND operator to determine if a number is even or odd. This works because the least significant bit (LSB) of all even numbers is 0, and the LSB of all odd numbers is 1.

```c
#include <stdio.h>

int main() {
    int num;
    printf("Enter an integer number :: ");
    scanf("%d", &num);

    int result = num & 1;
    if(result == 0)
        printf("\n%d is an EVEN number.", num);
    else
        printf("\n%d is an ODD number.", num);

    return 0;
}
```
