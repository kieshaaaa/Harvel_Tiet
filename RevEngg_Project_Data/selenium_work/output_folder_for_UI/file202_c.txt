#include <stdio.h>

int main() {
    int n, i, nthEven = 0;

### Version 3: Using arithmetic progression formula

The nth term of an arithmetic progression can be found with the formula: `a_n = a_1 + (n - 1) * d`, where `a_1` is the first term and `d` is the common difference. For even numbers, `a_1` is 2 and `d` is also 2. This simplifies to `nthEven = 2 * n`, which is the logic we started with, but I'll show an adjusted formula that doesn't do the calculation within the `printf` to meet your requirements.
