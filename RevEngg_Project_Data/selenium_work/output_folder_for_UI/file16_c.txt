**Version 1**: Use ternary operator to decide the result and print messages in a slightly different manner.

int main() {
    int number;
    printf("Enter a number: ");
    scanf("%d", &number);

    int divisible = (number % 5 == 0) ? 1 : 0;
    int result = divisible ? number + 1 : number + 2;
    
    if (divisible) {
        printf("%d is divisible by 5.\n", result);

        printf("%d is not divisible by 5.\n", result);
